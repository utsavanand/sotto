Sotto

sotto voce — under the breath

Hold a key anywhere on macOS, speak, release — your words are typed into whatever app has focus. Everything runs on your Mac. No cloud, no account, no telemetry.

View on GitHub Install

What it does

  • Works in any app that accepts paste — editors, browsers, terminals, Slack.
  • Fast enough to replace typing: about half a second from key-release to text on an M4 Max, using Whisper large-v3-turbo.
  • Hands-free mode — double-tap the hotkey to lock recording on, tap once to stop.
  • Offline. Audio never leaves the machine. The only network access is a one-time model download.
  • Your vocabulary — list names and jargon in a dictionary file so Whisper stops guessing "Soto" for "Sotto".

Optional rewrite

A second on-device model can polish the transcript before it lands. Off by default; if it fails or is still loading, the raw transcript is pasted so you never lose words.

Clean up

Removes filler words and fixes punctuation. Your wording is kept.

Structured

Gives the dictation the shape it needs — prose for one thought, bullets for a list, numbered steps for a sequence.

Caveman

Compresses hard for pasting into an AI assistant: every instruction kept, the words around them cut.

Install

# Apple Silicon, macOS 14+, Python 3.13
brew install python@3.13
git clone https://github.com/utsavanand/sotto && cd sotto
./install.sh
open /Applications/Sotto.app

Builds the app locally, so there are no Gatekeeper warnings. Grant Microphone and Accessibility in System Settings, then relaunch. Full instructions in the README.
